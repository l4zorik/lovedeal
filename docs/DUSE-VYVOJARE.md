## 🎯 PRAVIDLA PRO KÓD

### Před psaním kódu
1. **Pochop úkol** - co přesně mám udělat?
2. **Zkontroluj kontext** - co už existuje?
3. **Vyber správný nástroj** - React Native / Expo / Native?
4. **Dodrž styl** - jako předchozí kód

### Při psaní kódu
1. **Kompaktnost** - minimum řádků, maximum funkčnosti
2. **Čitelnost** - jasné názvy, logická struktura
3. **Bezpečnost** - žádné hardcoded hodnoty
4. **Testovatelnost** - funkce musí jít otestovat

### Po psaní kódu
1. **Otestuj** - spusť testy
2. **Zkontroluj** - projdi kód
3. **Dokumentuj** - aktualizuj docs
4. **Aktualizuj checklist** - +1

## 📋 CHECKLIST PRAVIDLA

### Struktura checklistu
```
[ ] Úkol (checkbox)
  ├── Popis (co přesně)
  ├── Čas (odhad)
  ├── Závislosti (co musí být hotovo předtím)
  └── Stav (pending / in_progress / completed)
```

### Aktualizace checklistu
```
PO KAŽDÉM ÚKOLU:
1. Označ jako [x] completed
2. Přidej datum dokončení
3. Připočti +1 k metrice
4. Zapis do CHANGELOG.md
5. Přezkoume další úkoly
```

### Automatické vylepšování
```
PO KAŽDÉM TÝDNU:
1. Projdi všechny checklisty
2. Přidej +1 ke všem metrikám
3. Aktualizuj prioritu úkolů
4. Přidej nové poznatky
5. Vylepši pravidla
```

## 🧠 DUŠE CHECKLISTU

### Osobní pravidla
```
1. ŽÁDNÉ EXCUSES - prostě to udělej
2. +1 KAŽDÝ DEN - každý den musí být pokrok
3. KOMPRAKTNOST - méně je více
4. TESTUJ - nikdy neposílej netestovaný kód
5. DOKUMENTUJ - budoucí já ti poděkuje
```

### Workflow
```
RÁNO:
  - Otevři checklist
  - Vyber 1 prioritu
  - Dokud není hotovo, nedělej nic jiného

BĚHEM DNE:
  - +1 po každém úkolu
  - Aktualizuj checklist
  - Loguj pokrok

VEČER:
  - Shrnutí dne
  - Plán na zítra
  - Aktualizuj metriky
```
