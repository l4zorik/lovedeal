# TikTok - Targeting System

## 5 hlavnich typu targetingu

### 1. Core Audience (Demographics)
- Lokace: zeme, region, mesto
- Vek: 18-24, 25-34, 35-44, 45-54, 55+
- Pohlavi: muz, zena
- Jazyk: cesky, anglicky, atd.
- Zarizeni: Android, iOS, oba

### 2. Interest Targeting
- Dlouhodobe zajmy uzivatele
- Kategorie: beauty, gaming, travel, finance, food, fashion
- Zaklad na obsahu kterym se uzivatel interaguje
- Nejlepsi ve spojeni s Core Audience

### 3. Behavior Targeting
- Kratkodobe akce (poslednich 15 dni pro video, 90 dni pro follow)
- Sledovani videi, like, share, komentare
- Followovani creatoru
- Interakce s reklamami

### 4. Custom Audiences
- Min. 1000 matched users pro aktivaci
- Zdroje:
  - Customer list upload (CSV - emails, telefonni cisla)
  - TikTok Pixel (page views, add-to-cart, checkout)
  - Engagement (video watchers, ad interactors)
  - App activity
  - Lead generation
- Nejnizsi CPA - re-engage existing useri

### 5. Lookalike Audiences
- 3 tier: Narrow, Balanced, Broad
- Narrow: nejvyssi similarity, mensi reach
- Broad: sirsi reach, nizsi similarity
- Min. 1000 users v source audience
- Nejlepsi vysledky z cistych dat (platici zakaznici > cold signups)

### Smart Targeting
- AI-powered automaticke targetovani
- Pixel data + creative signals
- Doporuceno: min. 50 konverzi tydne

---

## Targeting strategie podle kampane

| Typ kampane | Doporceny targeting |
|-------------|---------------------|
| Awareness | Broad + Interest |
| Conversion | Custom + Narrow Lookalike |
| Retargeting | Custom (site visitors, cart abandoners) |

## Chyby v targetingu
1. Prilis uzke targetovani na zacatku
2. Nedostatecny budget (musi byt 10-50x CPA)
3. Zmeny behem learning phase
4. Nespravna volba bidding strategie
